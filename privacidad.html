Política de privacidad de Estudio redes

Última actualización: 20 de octubre de 2026.

Qué es

Estudio redes es una herramienta privada que solo utiliza su propio titular para gestionar sus canales. No tiene usuarios externos.

Qué datos de Google usa

Con la autorización expresa del titular, la herramienta usa la YouTube Data API para subir vídeos al canal propio, ajustar su título, descripción, miniatura y privacidad, y leer las estadísticas y comentarios de ese mismo canal.

Del mismo modo, usa la API de Instagram (permisos de perfil básico y publicación de contenido) y la Content Posting API de TikTok (información básica del perfil y publicación de vídeos) únicamente para publicar en las cuentas propias del titular el contenido que este ha aprobado.

Dónde se guardan

Los tokens de acceso y los datos obtenidos se guardan únicamente en el ordenador del titular. No se envían a servidores de terceros, no se venden, no se comparten y no se usan para publicidad ni para entrenar modelos de inteligencia artificial.

Uso limitado

El uso y la transferencia de la información recibida de las APIs de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions. Al revocarlo, la herramienta deja de poder acceder a la cuenta y los tokens locales se eliminan.
